# AGENTS.md - Chimithèque Backend Agent Guide

First read and follow the global instructions in the [`AGENTS.md`](../chimitheque/AGENTS.md) file.

This `rust` crate is the REST API backend of the [`Chimithèque`](https://github.com/chimitheque/gochimitheque) application.\

## Specific project instructions

- The request handlers are in `src/handlers`. They validate the data with `chimitheque_types` (`sanitize_and_validate`), check it against the database, then call `chimitheque_db`, which assumes correct data.
- A database error means a check is missing in the Rust code: add the check instead of handling the error.
- Permissions are enforced by a casbin middleware on the item id of the request path. The policy, `src/casbin/policy.conf`, is generated by `chimitheque_utils/examples/casbin.rs`: do not edit it by hand. What casbin can not see, the request body, is checked in the handlers (`src/authorization.rs`).
